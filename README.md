Original 0x88 chess engine in Python, 4KB. `main.py` is an LZMA
payload from the kit's `makefun compress`. Negamax alpha-beta,
quiescence, transposition table, MVV-LVA + killer + history ordering,
null-move pruning, PVS + LMR, iterative deepening to a fixed 70,000
nodes a move. Deterministic, MIT licensed. Build log:
SESSION-TRANSCRIPT.md. Referral code: dwant4m4.
